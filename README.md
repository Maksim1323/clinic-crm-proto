# ClinicCRM / MedFlow — тестовый прототип

Интерфейс CRM клиники и экспериментальный Telegram-бот с выбором ИИ-провайдера и передачей диалога сотруднику. Существующий визуальный стиль сохранён. Репозиторий содержит **прототип, а не готовую медицинскую систему**.

## Быстрый старт

Требуется Node.js 20 или новее.

```bash
npm ci
npm start
```

Откройте `http://localhost:10000`. Для другого порта задайте `PORT`, например `PORT=8000 npm start`. Пока секреты не настроены, интерфейс открывается, но Telegram и ИИ не подключены.

```bash
npm test        # API + браузерный smoke-тест без реальных ключей
npm run test:api
npm run test:ui
```

## Важно

**Не вводите реальные сведения пациентов.** Автоответ ИИ выключен до явной настройки. GitHub Pages показывает только статический интерфейс; сервер и API необходимо разворачивать отдельно. Для тестового бота на Render сообщения при включённом ИИ отправляются выбранному ИИ-провайдеру, данные хранятся в PostgreSQL при настроенном DATABASE_URL, без него локально — во временной файловой системе. Личные учётные записи, базовые роли и журнал действий реализованы для прототипа; производственная безопасность, полноценный аудит и юридическая проверка отсутствуют.

Настоящие ключи и токены задавайте только в защищённых переменных окружения; не добавляйте их в Git и не присылайте в переписке.
